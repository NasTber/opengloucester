Accessibility

{{ site.name }} aims to meet WCAG 2.2 Level AA. That includes the WCAG 2.1 AA standard the 2024 ADA rule sets for state and local government websites.

  • Works with screen readers, keyboards, and zoom up to 200%.
  • Text and controls meet contrast requirements.
  • Color is never the only way information is shown.
  • Every chart has a table with the same numbers.
  • Pages work without JavaScript.

Testing

Every update is checked automatically on every page, at phone and desktop sizes, and isn't published if it fails. New sections are also checked by hand with a keyboard and screen reader.

Known issue

Most agendas and minutes the city posts are scanned images, which screen readers can't read. Where this site summarizes one, the full text is included as a readable version.

Report a problem

If something is hard to use, {{ contact(site) }}, with the page address. If you need information in another format, ask.
