About

An independent site tracking public data about the City of {{ town.name }}. Not run by or affiliated with the city.

How it works

  • Updated every morning from public sources.
  • Every number links to where it came from.
  • New agendas and minutes are in an RSS feed.
    • {% if config.summaries is defined %}
  • Summaries written by AI are labeled on each meeting page.
    • {% endif %}
  • Mistakes are corrected openly, with a note on the page.

Sources

    {% if config.seeclickfix is defined %}
  • 311 requests: SeeClickFix, public requests only, under a CC BY-NC-SA 3.0 license. How the 311 numbers work.
    • {% endif %}
  • Meetings, agendas, and minutes: the city's calendar and Archive Center. Copies are saved when posted. Minutes are collected from {{ config.archive.minutes_since | date("month") }} on.
    • {% if config.drive_meetings is defined %}
  • School Committee agendas and minutes: {{ config.drive_meetings.source_name }}, from the public folders linked on the School Committee website, from {{ config.drive_meetings.since | date("month") }} on.

  • Tax bill and city budget: Mass. Division of Local Services Municipal Databank, from the city's filings with the state.
    • {% endif %} {% if config.labor is defined %}
  • Unemployment: U.S. Bureau of Labor Statistics. City rates aren't seasonally adjusted, so each month is compared with the same month last year.
    • {% endif %} {% if config.schools is defined %}
  • Schools: Mass. Department of Elementary and Secondary Education open data. School-by-school detail is on the {{ config.schools.report_name }}.
    • {% endif %} {% if config.housing is defined %}
  • Housing: U.S. Census Bureau Building Permits Survey and American Community Survey (through Census Reporter), the state's Subsidized Housing Inventory, and Division of Local Services parcel counts.

  • Building and demolition permits: the city's Inspectional Services permit data on its Data Hub, used for the street lookup.
    • {% endif %} {% if config.seeclickfix is defined %}
  • Ward maps: MassGIS, 2022 boundaries.
    • {% endif %}
  • Street maps: OpenStreetMap, drawn with Leaflet. Map images load from OpenStreetMap's servers.

AI summaries

Meeting summaries, and the readable text of scanned agendas and minutes, are written by AI ({{ config.summaries.model | model_name }}, by Anthropic). They aren't checked by a person before posting. The city's document is the official record, and every summary links to it.

Privacy

We count visits so we know which pages are useful. That's all.

  • No cookies, no ads, and no tracking across other sites.
  • What you search for, and which street you look up, is never recorded.
  • Nothing that identifies you is kept, not even your IP address.

Counting is done by GoatCounter, a privacy-friendly service. It notes the page, the site that linked here, and your screen size, along with the browser type and rough location (such as the country or state) that every website can see. We only look at the totals.{% if config.analytics.public_stats %} They're public.{% endif %}
