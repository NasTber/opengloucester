What this section will show

  • Time to close: the median number of days from when a request is submitted to when it is closed, by category and by ward.
  • Open backlog: how many requests are still open and how long they have been waiting.
  • Trends: the same figures month by month.
  • Repeat locations: places where the same kind of problem is reported more than once within a short period.

Where the data comes from

Requests that residents submit through SeeClickFix, the city's service request system. Only public requests are included. Requests the city keeps private are not available and are not counted.

To report a problem, use the official City of {{ town.name }} website. This site does not accept reports.
