Affordable housing

Massachusetts counts homes that are kept affordable to lower-income households on its Subsidized Housing Inventory. Under Chapter 40B, the goal is for {{ s.goal_percent }}% of each community's year-round homes to be on the list. Below {{ s.goal_percent }}%, the state can override local zoning decisions on qualifying projects that include affordable homes.

As of {{ s.as_of | date("plain") }}, {{ s.shi_units | number }} of {{ town.name }}'s {{ s.year_round_homes | number }} year-round homes were on the list: {{ s.percent }}%.

{% if s.get("census_year") %}Year-round homes are from the {{ s.census_year }} Census. {% endif %} The state updates the list about every two years, with some changes in between. Source: Executive Office of Housing and Livable Communities, Subsidized Housing Inventory.
